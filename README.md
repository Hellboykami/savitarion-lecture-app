# Расшифровка лекций

Локальное приложение для Mac. Перетаскиваете в окно браузера материалы лекции — запись, конспекты, фото слайдов — и получаете расшифровку записи и разложенную папку лекции, готовую для загрузки в проект Claude.

Работает только на Mac (проверено на Apple Silicon). Всё происходит на вашем компьютере: приложение не ходит в интернет, записи и расшифровки никуда не отправляются.

## Что делает

- Переводит запись (`.m4a`, `.ogg`, `.mp3`, видео и другие форматы) в WAV через ffmpeg и распознаёт русскую речь через whisper.cpp (`whisper-cli`, модель large-v3-turbo).
- Если запись пришла частями, склеивает их по порядку — таймкоды идут сплошные.
- Проверяет расшифровку на «петлю», когда одна фраза повторяется много раз подряд, и предупреждает с таймкодом.
- Сама подставляет дату лекции: из записи внутри файла, из даты в имени файла или сегодняшнюю. Дату можно поправить.
- Раскладывает материалы по папке лекции:

  ```
  ~/study/<Предмет>/<ГГГГ-ММ-ДД>/
      расшифровка/   <дата> <предмет> — запись 1.srt и .txt
      запись/        исходные аудио и видео
      конспекты/
      слайды/        слайд-01, слайд-02… по порядку
      прочее/
  ```

- Ничего не перезаписывает: если имя занято, новый файл получает « (2)».
- Ведёт очередь: одновременно идёт одна расшифровка, остальные ждут; любую можно отменить.
- По окончании показывает системное уведомление и подсказывает, сколько файлов пойдёт в проект Claude.

## Что нужно установить

1. Homebrew — https://brew.sh
2. Программы распознавания и перевода звука — в Терминале:

   ```bash
   brew install whisper-cpp ffmpeg
   ```

3. Модель распознавания `ggml-large-v3-turbo.bin` (около 1,6 ГБ) из репозитория `ggerganov/whisper.cpp` на Hugging Face — в папку `~/whisper-models`:

   ```bash
   mkdir -p ~/whisper-models
   curl -L -o ~/whisper-models/ggml-large-v3-turbo.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
   ```

Python отдельно ставить не нужно: хватает системного `python3` версии 3.9 или новее. Приложение использует только его стандартную библиотеку.

## Как скачать и запустить

1. Скачайте репозиторий — `git clone` или на GitHub кнопка Code → Download ZIP — и положите папку приложения в домашнюю папку.
2. Один раз разрешите маку запускать файлы из этой папки — в Терминале:

   ```bash
   cd ~/<папка приложения>
   xattr -dr com.apple.quarantine .
   ```

3. Дважды щёлкните по `Lectures.command`. Откроется окно Терминала и страница приложения в браузере (адрес http://127.0.0.1:48731/).

Окно Терминала не закрывайте, пока пользуетесь приложением: закрытие окна выключает приложение и останавливает текущую расшифровку. Во время расшифровки не закрывайте крышку ноутбука — мак уснёт.

Если после скачивания ZIP ярлык не запускается, верните ему право на запуск: `chmod +x Lectures.command`.

## Настройки

На странице есть раздел «Настройки»: папка учёбы (по умолчанию `~/study`), список предметов и порог проверки на петлю (по умолчанию 5 одинаковых фраз подряд). Они хранятся в файле `settings.json` в папке приложения. Этот файл личный и в репозиторий не попадает.

## Проверка

```bash
python3 selftest.py
```

Все проверки занимают около полуминуты, без распознавания и без сети: вместо whisper-cli работает имитация.

```bash
python3 selftest.py --live <файл записи>
```

Живая проверка настоящими ffmpeg и whisper-cli на двухминутном куске записи. Сам файл записи только читается; результаты — в `test-root/live/`.

Посмотреть страницу без whisper-cli и модели: `python3 app.py --demo` — распознавание там имитируется.

## Как устроено

- `Lectures.command`, `app.py` — запуск.
- `lecapp/` — сервер и обработка лекций; только стандартная библиотека Python.
- `web/` — страница: обычные HTML, CSS и JavaScript без сборщиков, только системные шрифты.
- `testing/` — проверки и имитации программ для `selftest.py`.
- `pack_for_mac.py` — архив для переноса приложения на Mac с другого компьютера.

Сервер слушает только `127.0.0.1` и принимает изменения только со своей страницы, поэтому из сети приложение не видно.

Распознавание запускается как `whisper-cli … -l ru -mc 0 …`. Ключ `-mc 0` обязателен: без него модель на длинных записях начинает повторять одну фразу до конца файла.

## Важно: лекции охраняются авторским правом

Не выкладывайте записи и расшифровки лекций в этот репозиторий и в другие открытые места. Файл `.gitignore` не пускает их в репозиторий, но отвечает за это тот, кто публикует.
